# Prescripto - Smart Doctor Appointment Management System 🏥💻

A full-featured **MERN stack** web application designed to solve the real-world problem of long queues and inefficient patient management in hospitals and clinics. **Prescripto** offers online appointment booking, real-time updates, role-based dashboards, and Razorpay-powered payments to streamline healthcare scheduling for **patients, doctors, and administrators**.

## 🌐 Live Demo

- **User Website:** [https://prescripto-frontend-on2f.onrender.com](https://prescripto-frontend-on2f.onrender.com)
- **Doctor/Admin Panel:** [https://prescripto-admin-ciwl.onrender.com/doctor-profile](https://prescripto-admin-ciwl.onrender.com/doctor-profile)

---

## 🚀 Features

### ✅ For Patients
- Book appointments with available doctors
- Live status updates for each appointment
- Online payment integration with **Razorpay**
- View upcoming and past bookings
- Cancel appointments (with refund if eligible)

### 👨‍⚕️ For Doctors
- Secure doctor login
- View upcoming appointments and patient details
- Update live appointment status (Confirmed, Ongoing, Completed)
- Reschedule or cancel appointments
- Manage personal availability calendar

### 🛠️ For Admin
- Manage doctors and their schedules
- View system-wide analytics and logs
- Moderate users and oversee operations

---

## 🔧 Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Payment Gateway:** Razorpay
- **Authentication:** JWT-based
- **Deployment:** Render

---

## 💳 Razorpay Integration

- Secure and fast online payments for booking confirmation
- Payment status synced with appointment status
- Refund process on eligible cancellations

---

## 📊 Real-time Appointment Status

- Patient and doctor dashboards reflect **live updates**
- Admin has access to all appointments and system-wide status

---

## 👥 Multi-role Authentication

- Role-based routing and dashboard access for:
  - `Patient`
  - `Doctor`
  - `Admin`
